# Portfolio

Portfolio pribadi berbasis Next.js untuk Muhammad Rifqi.

## Stack
- Next.js 12
- React 17
- Tailwind CSS 2
- Font Awesome

## Menjalankan project

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Build production

```bash
npm run build
npm run start
```

## Struktur penting
- `pages/index.js` — halaman utama portfolio
- `components/` — section UI portfolio
- `assets/data/` — sumber data biodata, project, work experience, skill
- `public/` — aset statis seperti CV dan gambar
